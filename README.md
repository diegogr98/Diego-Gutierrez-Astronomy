# Diego Gutierrez  
## Computational Astrophysics | Relativistic Physics | Scientific Computing

This repository contains selected computational projects in astrophysics, 
general relativity, orbital dynamics, and statistical inference.  

The focus of this work is the numerical implementation of physical models, 
solution of differential equations, simulation of astrophysical systems, 
and uncertainty quantification using modern computational tools.

---

## Research Areas

### Relativistic Astrophysics
Numerical implementations of General Relativity and high-energy processes:
- Kerr spacetime geodesics
- Gravitational wave modeling
- Relativistic synchrotron radiation
- Gravitational ray tracing

Emphasis: tensor formalism, differential geometry, numerical integration.

---

### Celestial Mechanics
Orbital dynamics and multi-body gravitational systems:
- N-body simulations
- Circular Restricted Three-Body Problem (CRTBP)
- Near-Earth asteroid orbit characterization

Emphasis: dynamical systems, numerical solvers, stability analysis.

---

### Astrophysical Modeling
Physical modeling of astrophysical environments:
- Planetary interior layered models
- Seismic wave propagation
- Interstellar dust extinction modeling

Emphasis: physical modeling, PDE-based systems, computational simulation.

---

### Computational and Inference Methods
Statistical and data-driven approaches applied to physical systems:
- Bayesian inference and MCMC
- Uncertainty quantification
- CCD detector characterization
- SQL + Python data analysis

Emphasis: statistical modeling, parameter estimation, data pipelines.
